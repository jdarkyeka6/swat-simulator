# SWAT Simulator

PCVR tactical-response game built in Unreal Engine for testing with a Meta Quest 3S over Quest Link / Air Link.

## First playable goal

Build one replayable bank-robbery mission where the player can:

- move and interact naturally in VR
- open doors and clear rooms
- communicate with / command suspects
- arrest surrendered suspects
- protect and evacuate civilians
- take damage and fail the mission if incapacitated
- complete the mission with a score based on safety, arrests, evidence, and objectives

## Initial development stack

- Unreal Engine 5
- VR Template
- OpenXR
- PCVR first
- Meta Quest 3S as the test headset

## Milestone 1

1. VR player pawn
2. Smooth locomotion and turning
3. Greybox bank map
4. Physics/interactable doors
5. One suspect AI
6. Surrender state
7. Handcuff interaction
8. Basic player damage
9. Mission complete/fail logic

## Repository notes

Unreal-generated folders such as `Binaries`, `Intermediate`, `Saved`, and `DerivedDataCache` are intentionally ignored.
